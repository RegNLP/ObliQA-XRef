ObliQA-XRef Human Audit — Instructions

                

                
            

            

                
Goal: Audit dual-passage QA items for cross-reference relevance. Make all judgments
                    using only the displayed passages.

                
Scope: You will see a Question, a Source passage, and a Target passage. In some
                    items, an ID or a short “Reference Text” may appear near a passage; treat these as hints only—decide
                    based on the passages.


                
1) Question understandability

                
    
                    
  • Yes: the question is clear and understandable.
    • 
                    
  • No: wording is unclear, ambiguous, or ungrammatical.
    • 
                    
  • Partially / unclear: the question is only partly understandable or requires guessing.
    • 
                


                
2) Question phrasing / passage reuse

                
    
                    
  • Low reuse: the question is mostly rephrased and reads naturally.
    • 
                    
  • Moderate reuse: some key terms or phrases are reused, but the question is still naturally phrased.
    • 
                    
  • High reuse: large parts of the question closely follow the wording of the passages.
    • 
                    
  • Unclear: reuse level cannot be determined confidently.
    • 
                


                
3) Cross-reference connection type

                
    
                    
  • Strictly explicit: the source directly refers to the exact target rule/passage ID.
    • 
                    
  • Range-based explicit: the source refers to a rule range, section, chapter, or group that includes the target.
    • 
                    
  • Implicit / semantic: no explicit rule number/range is given, but the passages are conceptually connected.
    • 
                    
  • No relation: no clear connection between the passages.
    • 
                


                
4) Coverage / evidence dependency

                
    
                    
  • Both source and target provide necessary evidence: both passages appear needed.
    • 
                    
  • Only the source provides sufficient evidence: the Source passage appears sufficient.
    • 
                    
  • Only the target provides sufficient evidence: the Target passage appears sufficient.
    • 
                    
  • The provided passages do not clearly provide sufficient evidence / mismatch / unclear: evidence is incomplete, mismatched, or unclear.
    • 
                


                
5) Optional comment

                
Add a short note only if useful.
